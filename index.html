Main git commands

  • git status- команда яка відображає поточний стан змін та файлів
  • git branch - команда яка відображає список гілок в репозиторії
  • git add - індексує вказаний файл до наступного коміту
  • git commit - фіксує індексовані зміни і зберігає їх в історію версій
  • git push - завантажує зміни локальної гілки до віддаленого репозиторію
  • git checkout - перемикання між гілками
